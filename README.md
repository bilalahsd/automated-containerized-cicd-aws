# Automated Containerized CI/CD Deployment on AWS

A Cloud/DevOps project that demonstrates the complete path from application development to automated Kubernetes deployment on AWS.

## Current Stack

- Node.js
- Express.js
- Git
- GitHub

## Application

This project currently contains a simple Node.js REST API with:

- `GET /health`
- `GET /api/tasks`

## Project Roadmap

The application will progressively be extended with:

- Docker
- GitHub Actions
- Terraform
- AWS VPC
- Amazon ECR
- Amazon EKS
- Kubernetes
- Load Balancing
- CloudWatch
- Automated CI/CD deployment
